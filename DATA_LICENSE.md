# Data attribution and publication boundaries

Source: **Brazilian E-Commerce Public Dataset by Olist**, published by Olist on [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), version 2. The source lists **CC BY-NC-SA 4.0**. [License text](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Olist retains rights in the source data. This repository attributes the publisher and identifies the pinned download and file fingerprints in `reports/source_manifest.json`. Raw CSVs and the original archive are not committed.

Aggregate CSVs, observed-result summaries and the overview graphic are transformations of that source: joins, filtering, deduplication, cohort construction and aggregation are described in the methodology. Treat redistributed source-derived material under the applicable attribution, noncommercial and share-alike conditions. Check the source license before commercial reuse; public availability is not a waiver of restrictions.

The dataset license does not automatically grant a license to original application code. This publication does not apply a separate open-source code license. GitHub's public visibility alone should not be read as permission for unrestricted code reuse.
